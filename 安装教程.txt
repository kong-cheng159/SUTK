================================================================
              SUTK 修改器 · 安装教程（文字版）
================================================================

适用游戏：Seres Universalis: Three Kingdoms（Demo）
适用系统：Windows 10 / 11（64 位）
不需要安装 Python，不需要管理员权限，不修改游戏本体。

----------------------------------------------------------------
〇、如果你用的是「SUTK修改器.exe」桌面版（可跳过本文）
----------------------------------------------------------------

  便携包里若有 desktop-app\dist\SUTK修改器\ 或已打包的同名文件夹：
    · 双击 SUTK修改器.exe，不用跑 1 安装.bat
    · 详细步骤见：桌面版使用说明.md、README.md
    · 发给别人.txt 在 desktop-app 目录

  下面从「一」开始是控制台版（bat + 热键）的安装教程。


----------------------------------------------------------------
一、先解压
----------------------------------------------------------------

1. 把 SUTK修改器_便携版.zip 解压出来。
   右键 →「全部解压缩」→ 选一个文件夹，例如 D:\SUTK修改器

   注意：不要在压缩包里直接双击运行，必须先解压出来。

2. 解压后应该看到这些文件（顺序是编号，照着数字点就行）：

      1 安装.bat
      2 启动修改器.bat
      3 卸载并还原.bat
      安装教程.txt      ← 就是本文
      使用说明.md
      控制台.bat
      launcher.cmd
      SUTKMod.pyw
      MemScan.py
      python\           ← 自带的运行环境，不要删、不要动


----------------------------------------------------------------
二、安装（只做一次）
----------------------------------------------------------------

3. 双击「1 安装.bat」

   会出现一个黑色窗口，显示 4 行结果，例如：

      [1/4] 存档处理   完成 3 / 已是最新 3 / 失败 0
      [2/4] 桌面图标   C:\Users\你的名字\Desktop\SUTK 修改器.bat
      [3/4] 开机启动   未开启(默认不装)
      [4/4] 后台热键   已启动 pid=12345

   看到这 4 行就说明装好了，不需要再做别的操作。
   紧接着它会自动打开控制台菜单，按 0 退出即可。

   · 如果第 2 行显示「创建失败」，不要紧，
     以后每次直接双击文件夹里的「2 启动修改器.bat」也能用。

   · 如果第 1 行全部是「完成 0 / 已是最新 N / 失败 0」，
     说明存档之前已经改过了，属于正常。


----------------------------------------------------------------
三、每次玩游戏怎么用
----------------------------------------------------------------

4. 双击桌面上的「SUTK 修改器」

   它会做三件事：
     ① 后台启动（这样游戏里能按热键）
     ② 打开控制台菜单
     ③ 自动给所有存档打好补丁

   控制台菜单长这样：

       ---- 应用（会先列存档，让你选编号）----
       [1] 应用修改（按下面「已勾选模块」执行）
       [2] 选择要改的项目    ← 只想满科技就勾科技，不想满金币就不勾
       [3] 自定义目标数值
       [4] 撤销还原

       ---- 快捷（只改一项，同样先选存档）----
       [5] 只满科技
       [6] 只满金币
       [7] 只满兵役 + 粮食
       [8] 只满兵力

       ---- 武将六维（统率/武力/敏捷/智力/政治/魅力）----
       [G] 六维修改（批量设值 或 单个武将逐个改）

       ---- 批量 ----
       [9] 一键改【全部】存档（按已勾选模块）

       ---- 高级 ----
       [B] 内存定位（CE 式）
       [C] 势力好感 / 同盟 / 停战
       [D] 完全卸载

       [0] 退出

5. 选 1，回车。它会列出所有存档并自动编号：

       编号  存档名                              修改时间   大小   状态
        [ 1] 刘宠-初平元年(190)正月初五丑时.sav  10-24 18:28  240K  原档  <- 最近游玩
        [ 2] 曹操-建安元年(196)正月十一子时.sav  10-24 18:25  279K  已修改
        [ 3] 12-初平四年(193)九月初七辰时.sav    10-24 18:25  276K  已修改

       应用到哪个存档：输入编号 1 / 1,3 / 1-3   A=全部
                      回车=最近游玩   Q=取消

   直接敲编号回车就行，不用打存档名。
   想一次改多个：1,3 或 1-3。想全改：A。

6. 关闭控制台窗口，进游戏，读取存档。

   ★ 重点：改的是存档文件，所以必须「重新读档」才会生效。
     当前正在玩的那一局，数值不会当场变。


----------------------------------------------------------------
四、游戏里随时呼出（重点）

先搞清楚：桌面那个「SUTK 修改器」是文件，只能双击，不能"在游戏里按"。

正确顺序：
  1) 开游戏之前，先在桌面双击「SUTK 修改器」
     窗口会显示菜单 —— 这个窗口不用关，最小化就行
     （它的作用是让后台常驻，热键才有效）
  2) 进游戏
  3) 任何时候按 Ctrl + Alt + F9，控制台直接从游戏画面上弹出来

备用热键：Ctrl+Alt+F10 / Ctrl+Shift+F9 / Ctrl+Alt+F11 / Ctrl+Alt+S

热键没反应？按这个顺序查：
  - 先看菜单窗口是不是被你关掉了（关了 = 后台死了 = 热键失效）
  - 双击程序目录的「诊断.bat」，第 4 项显示 [OK] 才说明热键可用
  - 游戏如果是"独占全屏"，窗口会被盖住，改成"无边框窗口"

另外：目录里如果有个 SUTK控制台.hta，那是旧版残留，已经废弃，
     双击没反应是正常的，直接删掉。现在只用「控制台.bat」。


----------------------------------------------------------------

游戏运行中，按 Ctrl + Alt + F9  可以呼出控制台。

     如果没反应，依次试这几个：
       Ctrl + Alt + F10
       Ctrl + Alt + F11
       Ctrl + Shift + F9
       Ctrl + Alt + S

     仍然没反应，说明后台没在跑：
     先双击桌面「SUTK 修改器」，再回游戏按。

     提示：游戏用「独占全屏」时，窗口会被游戏盖住。
     把游戏显示模式改成「无边框窗口」就正常了。


----------------------------------------------------------------
五、只要某一项？模块可以单独勾
----------------------------------------------------------------

8 个项目互相独立，勾哪个改哪个，没勾的一个字节都不动：

      1 金钱        2 兵役        3 粮食        4 科技全满
      5 可供给上限   6 部队满编     7 自动开关     8 武将六维

用法：
  控制台选 2  →  看到 [√]/[ ] 列表  →  输入编号切换勾选
              →  输入 Q 结束  →  问「现在应用吗」按 Y

  想只满科技：把 4 勾上，其它全取消（先按 N 全不选，再输入 4）
  想只满金币：快捷选 6 一步到位

也可以直接敲命令（高级）：
  launcher.cmd --apply --sections tech          只满科技
  launcher.cmd --apply --sections money,food    只改金钱和粮食

注意：勾选会被记住，之后游戏启动时后台也按这套勾选自动执行。
想恢复"全都改"，控制台选 2 → 按 A 全选 → Q → Y。


----------------------------------------------------------------
六、新开局怎么弄
----------------------------------------------------------------

新开局时游戏还没有存档文件，所以工具没法改。按这个顺序：

     开局  →  在游戏里存一次档  →  退出到主菜单  →  重新载入那个档

工具会在存档落盘后几秒内自动改好（后台开着的话），
并弹窗告诉你「新存档已修改」，这时退出重载就行。


----------------------------------------------------------------
七、城市归属（把城给别人 / 给自己）

⚠️ 先说最重要的一条：**不要把某个势力的城全部抢光**。
   这个游戏版本没有"势力灭亡"机制，势力变成 0 城但还存在时，
   游戏 AI 会卡死（实测 31 个 0 城势力直接卡崩）。
   
   工具现在会自动保护：整国端走时，会给你留它 1 座城（优先首都）。
   真卡崩了也别慌，控制台按 M 再按 4，选「修复」就能救回来。



1. 控制台按 M，进入「城市归属」
2. 选 1 可以先看全图：每个城归谁、谁是首都（★）
3. 选 2 开始转移：
   - 先输城市编号：1 = 第一座，1,3 = 第一和第三，1-5 = 一到五
   - 想整国端走：输 @43（43 是势力编号，左边的表里能看到）
   - 再选给哪个势力（自己也在列表里，想给自己就选自己）
   - 城内太守：默认留在原势力（推荐），也可以选跟着城一起转
4. 确认 Y 之后会显示改了哪几座，并自动做一致性检查

补充：
- 城的建筑、资源、人口、守军都跟着城走，不用另外改
- 城外的野战部队不跟城走（它们是按地图位置站着的）
- 首都被转走时，工具会自动给它换一个首都
- 拿走某势力最后一座城会提示「该势力已无城市」，建议先备份存档
- 改完要：退出到主菜单 -> 重新载入该存档


七点五、改坏了怎么退回去（自动留底，不用你手动存）

  工具会在自己的 history 文件夹里，把"每次改之前的样子"存一份。
  游戏自己存档时也会留一份。你什么都不用做，它自动存。

  按 M -> 7 ：看有哪些版本（每个存档能看到有几份）
  按 M -> 6 ：回滚
      第一步：选哪个存档（输编号）
      第二步：退到哪一份（1 = 最近，最后一项是「原始档」）
      第三步：输 Y 确认

  · 「原始档」= 工具第一次动手之前的原始存档，永远都在
  · 退错了不要紧：回滚前会把当前内容再存一份，还能再退回来
  · 每个存档最多留 30 份，满了自动删最老的
  · 这些快照存在工具目录，不会混进游戏的存档列表

  存档太多了怎么办？
     · 你在游戏里删掉的存档，本地副本会自动跟着清（进回收站，7 天后删）
     · 游戏自己自动存档时，本地默认「不留底」，只有工具改档前才留
       想改：控制台按 A -> 3
     · 想立刻清一次：控制台按 M -> 8（或 A -> 4）
     · 每个存档最多留 30 份，满了自动删最老的



八、卸载
----------------------------------------------------------------

7. 双击「3 卸载并还原.bat」，输入 Y 回车。

   它会：
     · 把全部存档还原成修改前的原始状态
     · 删除桌面图标
     · 清除开机启动项

   然后这个文件夹可以直接删掉，不留任何残留。

九、常见问题

Q0：双击图标后黑框一闪就没了 / 热键按不了，怎么办？
   先双击程序目录里的「诊断.bat」，等它跑完（约 10 秒），
   它会生成「诊断结果.txt」并直接显示在窗口里。
   把那个文件发给开发者，就能定位。
   
   急用的话，直接双击「控制台.bat」——它不依赖后台，一定能打开。
   热键（Ctrl+Alt+F9）需要"诊断结果"第 4 项显示 [OK] 才有效。


----------------------------------------------------------------

Q1：双击「SUTK 修改器」没反应，或者黑框一闪就关？
    · 先直接双击文件夹里的「控制台.bat」——它不依赖任何启动逻辑。
      能正常出现菜单，就说明程序没问题；
      如果这样也打不开，把报错内容发我。
    · 常见原因：用记事本手动编辑过 .bat（会被存成 UTF-8 或 LF 换行，
      Windows 解析失败）。解决办法：重新解压一份，不要用记事本另存。
    · 想看清楚闪退的报错：右键 bat →「编辑」看一眼；
      或者在这个文件夹的地址栏输入 cmd 回车，再敲 2 启动修改器.bat。

Q2：杀毒软件报毒？
    这是 Python 程序被打包成 exe/bat 的常见误报。
    工具只读写你自己电脑上的存档文件，不联网、不修改游戏本体。
    可以加入信任（白名单）。介意的话就不要用。

Q3：游戏里数字没变？
    · 确认已经「重新读档」，不是只回到游戏画面
    · 确认控制台里显示「完成 N」而不是「失败 N」
    · 确认改的是你正在读的那个存档（菜单 7 只改最近游玩的）

Q4：金钱显示不对 / 变成负数？
    数值超过了游戏上限（2,147,483,647）。
    菜单 6 里改小一点，例如金钱填 999999999。

Q5：部队还是不满？
    菜单里选 8（只满兵力），它会按各兵种自己的上限把部队补满、
    并把伤兵清零（不同兵种上限不同，15000/16000/14000 都有）。
    改完同样需要重新读档。

Q6：我新开一局 / 自建势力，工具能自动认出来吗？
    能。存档列表是实时读目录的，新档一出现就排在第一位；
    后台开着的话，5 秒内会自动打补丁并弹窗告诉你。
    自建势力也认——工具是按「玩家控制」标记找的，不是写死的势力编号。

Q7：后台/热键一会儿就没了？
    后台是独立进程，关掉控制台窗口不影响它。
    但重启电脑后不会自动启动（默认不装开机启动），
    需要重新双击桌面「SUTK 修改器」。

Q8：想恢复原样但不想卸载？
    控制台选 3「撤销还原」，存档会逐字节还原成原始文件。

十、文件说明（不用记，出问题时对照）
----------------------------------------------------------------

  1 安装.bat          一次性安装：处理存档 + 建桌面图标 + 启动后台
  2 启动修改器.bat    日常入口，等价于双击桌面图标

  SUTKMod.pyw         主程序（存档读写 / 补丁 / 后台监视）
  MemScan.py          内存扫描器（真·实时修改，需管理员权限）
  python\             自带 Python 运行环境，删了就不能用了

存档位置：
  C:\Users\你的名字\AppData\Local\ProjectA\Saved\Saves

备份位置：
  与程序同目录下的 backup\  （首次应用时自动生成）
