# 游戏与路径说明

## 游戏本体（Steam Demo）

| 项 | 说明 |
|----|------|
| 名称 | **Seres Universalis: Three Kingdoms（Demo）**（Steam 库中常见文件夹名：`Seres Universalis Three Kingdoms Demo`） |
| 示例安装目录 | `D:\Program Files (x86)\Steam\steamapps\common\Seres Universalis Three Kingdoms Demo` |
| 修改器是否改这里 | **否**。工具只读写用户存档，不写入 Steam 游戏目录。 |

本机若装在其他盘，把下面命令里的路径换成你的 **Steam → 右键游戏 → 管理 → 浏览本地文件** 打开的目录即可。

### 常用子路径（开发 / 提取资源）

| 用途 | 典型相对路径（在安装目录下） |
|------|------------------------------|
| 进程名（内存扫描） | 运行后进任务管理器可见 **`SUTK-Win64-Shipping.exe`** |
| 本地化 / 兵种中文表 | `ProjectA\Content\Localization\Game\zh-CN\Game.locres`（或在 `Content\Paks\` 的 pak 内，见 `desktop/tools/build_troop_kinds.py`） |
| Pak 包 | `ProjectA\Content\Paks\pakchunk0-Windows.pak`（以实际文件名为准） |

更新兵种中文表示例：

```powershell
cd "E:\JZ-ROS\TEST\SUTK修改器_便携版"
$env:OO2PATH = (Resolve-Path "desktop\tools").Path
$PAK = "D:\Program Files (x86)\Steam\steamapps\common\Seres Universalis Three Kingdoms Demo\ProjectA\Content\Paks\pakchunk0-Windows.pak"
.\python\python.exe desktop\tools\build_troop_kinds.py $PAK
```

## 用户存档与自建模板（修改器主要读写）

| 项 | 路径 |
|----|------|
| 存档 `.sav` | `%LOCALAPPDATA%\ProjectA\Saved\Saves\` |
| 自建武将模板 | `%LOCALAPPDATA%\ProjectA\Saved\ExternPersonage.sav` |
| 游戏崩溃日志（排错） | `%LOCALAPPDATA%\ProjectA\Saved\Crashes\` |

桌面版可在 **设置** 里改存档目录 / Extern 路径；留空则使用上表默认位置。

---

## 修改器程序目录

| 版本 | 典型位置 |
|------|----------|
| 桌面便携版 | 解压或打包后的 `SUTK修改器.exe` 同目录（含 `config.json`、`backup\`、`history\`） |
| 控制台版 / 开发仓库 | 仓库根目录（`SUTKMod.pyw`、`python\`） |

## 与《华夏风云》控制台修改器

[contrib/hxfs-save-editor](../contrib/hxfs-save-editor/) 使用 **同一套** `%LOCALAPPDATA%\ProjectA\Saved\Saves` 存档格式，与 Steam 安装目录无直接读写关系。
