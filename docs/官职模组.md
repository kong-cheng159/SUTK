# 官职模组（修改器 + 游戏 pak）

与「自建武将模板 / `desktop/data`」同一思路：**改 JSON → 修改器立刻多出行**；要让**游戏内**任免面板也认，还要动 **pak 数据表**。

## 1. 修改器层（存档 `info.official`）

编辑：

`desktop/data/officials_mod.json`

```json
{
  "version": 1,
  "append_rows": [
    {
      "id": "4091",
      "name": "破虏将军",
      "level": 8,
      "staffing": 11000
    }
  ],
  "override_rows": [
    {
      "id": "144",
      "name": "大司马（覆盖显示名）",
      "level": 9,
      "staffing": 15000
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `append_rows` | **新 id**，在汉系 1–144 之外追加到官职页 |
| `override_rows` | **同 id 覆盖**职名、等级、编制（修改器展示与自动任命用） |
| `level` | 1–9 星；俸禄仍按 `level×2+2` |
| `staffing` | 编制；不写则用 `(level+3)×1000` |

保存后 **刷新官职页**（或重启界面服务）。  
任免、自动任命、清空汉系任职都会作用于 **基准 144 + 模组行** 的全部 id。

官职页 → **打开官职模组**（或手动打开上述路径）。

**可追加全表（566 条，不在汉系 1–144）**：[官职模组_可追加全表.md](官职模组_可追加全表.md)；JSON：`desktop/data/officials_append_catalog.json`。

当前默认模组已写入 **6–9 星将军 + 文职共 142 条**（见 `officials_mod.json` 的 `append_rows`）。

> **id 建议（推荐）**：用全库已有但未进汉系 1–144 的 id（见 [官职列表.md](官职列表.md)）。例：当前模组用 **4091**（破虏将军、8 星）——**不改游戏也能任命且有效果**；修改器与游戏内职名一致。全新 id（如 701）须同步改 pak 增行，见 [游戏内新增官职操作步骤.md](游戏内新增官职操作步骤.md)。

## 2. 游戏层（pak / DT_Official）

修改器**不能**代替改 pak。要在 **`BP_OfficePanel`** 里多一行或改编制/效果，需要：

1. **`DT_Official`**（`ProjectA/Content/.../DT_Official.uasset`）增加或改行：与模组 **同一 id**、等级、编制等。  
2. **本地化** `Game.locres`：`OfficialName_*` 等键与职名。  
3. **爵位路线 / 面板绑定**：汉系 `han*` 爵位下列表来自数据表配置；新 id 若不在原 1–144 绑定段，还要改对应 **Rank / Office 列表**（具体字段以你解包为准）。

工具链与兵种表类似，见 `desktop/tools/README.md`（`repak.exe`、`build_officials.py` 从 locres 抽 710 职名）。

**给操作员的逐步说明（含 4091 破虏将军 / 701 示例、FModel、小 pak）：**  
→ [游戏内新增官职操作步骤.md](游戏内新增官职操作步骤.md)

## 3. 推荐工作流

1. 在 [官职列表.md](官职列表.md) 选一个 **未占用的 id**（或计划要在 DT 里新建的行号）。  
2. 写入 `officials_mod.json` → 修改器验证任免 / 自动任命。  
3. 按 [游戏内新增官职操作步骤.md](游戏内新增官职操作步骤.md) 改 `unpack_out` → `pack.ps1` → 进游戏读档对照。  
4. 需要分发时：带上 `desktop/data/officials_mod.json` + 小 pak（或打包脚本会复制 `desktop/data/`）。

## 4. 与自动任命

自动任命：**先高星后低星**填岗；每岗取 **统+武+敏** 最高者（可改任升星/同星更优 id）。汉系与模组追加职 **同一规则**。仍 **不任命太守、副将、君主**。
