# SUTK 修改器 · 桌面版使用说明

适用：**Seres Universalis: Three Kingdoms（Demo）**  
系统：**Windows 10 / 11（64 位）**  
入口：便携文件夹内 **`SUTK修改器.exe`**（整个文件夹一起拷贝，不要只发 exe）。

---

## 1. 安装与运行

| 项目 | 说明 |
|------|------|
| 是否需要 Python | **不需要**（文件夹内自带 `python\`） |
| 是否需要 Rust | **不需要**（仅开发者打包时需要） |
| WebView2 | 需 **Microsoft Edge WebView2**；Win10/11 通常已自带 |
| 游戏目录 | **不会**修改 Steam 安装目录，只改用户存档 |

**存档默认位置：**

`%LOCALAPPDATA%\ProjectA\Saved\Saves`

可在 **设置 → 存档路径** 改为其它文件夹（例如备份盘上的 Saves 副本）。

**本工具产生的文件（均在 exe 同目录）：**

| 路径 | 含义 |
|------|------|
| `config.json` | 模块勾选、数值上限、编队预设等 |
| `backup\` | 每个存档首次被改前的 `.orig` 备份 |
| `history\` | 每次改档前的快照（可回滚） |
| `mod.log` / `desktop\server.log` | 运行日志 |
| `port.txt` | 当前本地 API 端口（一般不用管） |

## 2. 基本流程

```
选存档 → 勾选要改的模块 → 应用修改 → 游戏内重新读档
```

1. 窗口**顶部下拉框**选择目标 `.sav`。
2. 左侧 **存档**：勾选要批量处理的存档（可多选），勾选 **模块**，点 **应用修改**。
3. 关闭或最小化修改器均可；改的是磁盘上的存档文件。
4. 进入游戏：**主菜单 → 载入该存档**（不是回到上一局继续玩）。

顶部标签会提示游戏是否在运行；运行中修改后同样需读档。

## 3. 侧栏功能一览

| 菜单 | 作用 |
|------|------|
| **存档** | 列表、模块、上限、六维目标、应用/还原 |
| **武将** | 当前档武将六维查看与编辑（★ 为名录外自建） |
| **城市** | 城市列表、搜索、转城、任命太守、修复等 |
| **编队 → 编队预设** | 维护「主将 + 副将1 + 副将2」模板，保存到 `config.json` |
| **编队 → 创建编队** | 勾选预设 + 选目标城，写入存档 |
| **编队 → 存档部队** | 查看当前档已有三人部队 |
| **外交** | 势力关系、同盟、停战等 |
| **检查** | 一致性审计（改档后建议跑一遍） |
| **内存** | 内存扫描写值（高级，需管理员，与存档改法不同） |
| **说明** | 加载 `经验总结.md` |
| **记录** | 本次会话操作日志 |
| **设置** | 存档路径、Extern 路径、启动后台热键等 |

控制台版里的 **Ctrl+Alt+F9** 热键可在设置里尝试启动 watcher；图形界面本身不依赖热键。

## 4. 存档页 · 模块说明

与 `SUTKMod.pyw` 一致，可单独勾选：

| 模块 | 典型效果 |
|------|----------|
| 金钱 / 兵役 / 粮食 | 拉到配置上限（注意 int32 上限） |
| 科技 | 科技树补满 |
| 可供给上限 | supply 等 |
| 部队满编 | 按**兵种各自上限**补兵，伤兵清零，只升不降 |
| 自动相关 | 见设置（默认建议关闭自动改档） |
| 武将六维 | 按目标值批量设置 |

**范围**：设置里可选仅玩家势力或全部势力（`scope`）。

**撤销**：存档页可对选中档做还原（依赖 `backup\` 内 `.orig`）；全量还原在控制台版有更严格限制，桌面版按接口提示操作。

更细的数值与版本说明见 **[使用说明.md](./使用说明.md)**（偏控制台，但模块语义相同）。

## 5. 城市

1. 顶部选好存档后进入 **城市**，列表加载该档所有城。
2. **搜索**支持中文城名、内部 key、势力、太守等。
3. **转城**：勾选城市 → 选择目标势力 → 确认（注意不要将某势力扣到 0 城，详见经验总结）。
4. **任命太守**：对己方无太守城批量或单城任命（按武将适性等规则，见界面说明）。
5. 改完后 **重新读档**。

城市中文名来自 `desktop/cities_zh.json`；太守名会结合存档武将与 `names_zh.json`。

## 6. 编队（三人部队）

游戏内一支「部队」= **1 主将 + 2 副将**，附带 **兵种**（`troopKindId`，如 `49_2`）与可选 **游戏编组**（`gameTeamId`）。

> 这与存档里 `teamInfos` 的「多队编组」不是同一概念；本工具编组指单支三人队。

### 6.1 编队预设

- 内置 **10 条** 模板（名称、三名武将 GUID、兵种、编组），首次运行会与 `config.json` 合并补全。
- 可 **新建 / 编辑 / 删除**；**保存预设** 写入 exe 目录的 `config.json`。
- **从存档导入**：把当前档每支三人队拉成预设（记得再点保存）。
- **兵种**列显示中文（如「鲜卑精锐」），数据来自 `desktop/troop_kinds_zh.json`；悬停可见 ID。
- 编辑时兵种仍填 **ID**（写入存档需要），例如 `49_2`。

### 6.2 创建编队

1. 在 **编队预设** 维护好模板并保存。
2. **创建编队**：勾选一条或多条预设 → 选择 **目标城市**（须为玩家势力城市）→ 写入。
3. 到 **存档部队** 核对主将/副将/兵种是否正确。
4. 游戏中对该城 **重新读档** 后查看。

### 6.3 存档部队

只读展示当前档已有部队；不负责删除或移动地图上的军队。

## 7. 武将与外交

- **武将**：显示中文名（名录武将从 `names_zh.json` 映射；自建武将名在存档内）。
- **外交**：修改前确认存档已选；写盘后读档生效。

## 8. 检查（审计）

改城、改编队、批量应用后建议运行 **检查**，查看硬性不变量与基线对比问题。  
原理与控制台 **`V` 审计** 相同，详见 **使用说明.md** 与 **经验总结.md**。

## 9. 设置

| 项 | 说明 |
|----|------|
| 存档路径 | 空 = 游戏默认 Saves；可选手动路径或 Tauri 下浏览文件夹 |
| Extern 路径 | 自建武将外部档，默认 `%LOCALAPPDATA%\ProjectA\Saved\ExternPersonage.sav` |
| 配置保存 | 模块、上限、路径等写入 `config.json` |
| 后台热键 | 调用 `SUTKMod` watcher（与控制台后台类似） |

## 10. 与控制台版的关系

| 项目 | 桌面版 | 控制台版 |
|------|--------|----------|
| 核心逻辑 | 共用 `SUTKMod.pyw` | 同上 |
| 配置 | exe 旁 `config.json` | 工具目录 `config.json`（若分开拷贝则两份） |
| 编队 / 城市 UI | 图形界面 | 控制台 `M` 等菜单 |
| 热键 | 可选启动 watcher | 安装 bat 后常用 |

同一目录同时保留 **控制台 bat** 与 **桌面 exe** 时，请留意是否共用同一份 `config.json`（桌面 exe 以 **SUTK_APP_DIR** 即 exe 目录为准）。

## 11. 常见问题

**Q：打开 exe 白屏或闪退？**  
看 `desktop\server.log`、`mod.log`；确认 `desktop\static\index.html` 与 `python\python.exe` 存在且未被杀毒隔离。

**Q：界面有了但存档列表空？**  
设置里检查存档路径；游戏是否至少存过一次档。

**Q：编队预设只有 6 条？**  
完全退出 exe 再开；或删除 exe 旁错误 `config.json` 后重启（会按内置十支补全，**先备份 config**）。

**Q：兵种显示还是 ID？**  
确认 `desktop/troop_kinds_zh.json` 存在；更新游戏版本后可按 **开发说明** 重新生成该文件。

**Q：改完游戏没变化？**  
必须 **主菜单重新读档**。
