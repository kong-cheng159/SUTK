# SUTK 修改器 · 桌面版开发说明

架构：**Tauri 2** 窗口加载本地静态页 → 通过 **HTTP** 调用同目录 **Python** 运行的 **`desktop/server.py`** → **`SUTKMod.pyw`** 读写存档。

```
┌─────────────────┐     127.0.0.1:8765      ┌──────────────┐     import     ┌─────────────┐
│  Vue 3 (Naive)  │  ───────────────────►  │  server.py   │  ───────────►  │ SUTKMod.pyw │
│  desktop/web    │      /api/*            │  Threading   │                │  MemScan.py │
└─────────────────┘                        └──────────────┘                └─────────────┘
        ▲
        │ Tauri WebView（release）或 devUrl
        └ sutk-mod.exe
```

---

## 1. 目录

| 路径 | 说明 |
|------|------|
| `desktop/web/` | Vue 3 + Vite + Naive UI 源码 |
| `desktop/static/` | `npm run build` 产物（server 静态托管） |
| `desktop/server.py` | REST 路由、中文名表、Capture 日志 |
| `desktop-app/src-tauri/` | Rust 启动器：设 `SUTK_APP_DIR`、起 Python、开 WebView |
| `SUTKMod.pyw` | 存档逻辑（桌面与控制台共用，尽量少改 breaking） |

---

## 2. 本地联调（浏览器 + API）

**不要**只跑 `npm run dev`（没有 API 会空数据）。

在 `desktop/web`：

```powershell
.\dev.ps1
# 或 npm run dev:full
```

流程：

1. 用仓库 **`python\python.exe`** 启动 `desktop/server.py --port 8765 --no-browser`
2. Vite **5173**，`/api` 代理到 **8765**

浏览器打开 `http://localhost:5173/`。  
Tauri 专有功能（文件夹选择）在纯浏览器下会提示用 exe。

---

## 3. 仅改前端

```powershell
cd desktop/web
npm install
npm run build
```

产物写入 **`desktop/static/`**。  
便携 dist 需再跑 **`desktop-app\build.ps1`** 或手动复制 `static` 到 dist。

---

## 4. 仅改 Python API / SUTKMod

1. 编辑 `SUTKMod.pyw` 或 `desktop/server.py`
2. 重启 Python 服务（关闭 exe 或结束占用 8765 的进程）
3. 若只改了 `server.py`，dist 用户只需覆盖 `desktop/server.py`

**约定**：`server.py` 顶部注释——优先通过调用 `M.xxx` 扩展，避免在 server 里重复存档格式逻辑。

---

## 5. 主要 API（节选）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/status` | 配置、模块、存档目录状态 |
| GET | `/api/saves` | 存档列表 |
| POST | `/api/apply` | 应用修改 |
| GET | `/api/generals` | 武将列表（含 `cn`） |
| GET | `/api/cities` | 城市列表 |
| POST | `/api/cities/assign-prefects` | 批量太守 |
| GET | `/api/troop-kinds` | 兵种中文映射 |
| GET | `/api/team-presets` | 编队预设（含内置补全） |
| POST | `/api/team-presets/save` | 保存预设 |
| GET | `/api/teams` | 当前档部队 |
| POST | `/api/teams/deploy` | 按预设创建编队 |
| GET | `/api/guide` | `经验总结.md` 文本 |

完整路由见 `server.py` 末尾 `ROUTES` 字典。

---

## 6. 前端状态

- **`desktop/web/src/store.js`**：存档、配置、编队、兵种表等 reactive 状态  
- **`constants.js`**：侧栏 `MENU`（含编队子菜单）  
- 进入某页时 **`refreshPage(key)`** 拉取对应数据  

---

## 7. Tauri 调试

```powershell
cd desktop-app
cargo tauri dev
```

需先构建前端或保证 `devUrl`（8765）已有服务；具体以 `tauri.conf.json` 的 `build.devUrl` 为准。

Release：`cargo tauri build --release` 或见 **打包说明.md**。

## 8. 中文数据文件

| 文件 | 生成方式 |
|------|----------|
| `names_zh.json` | 从 `Game.locres` 解析 `FullName_*`（脚本见历史对话 / 可复用 locres 解析逻辑） |
| `cities_zh.json` | 城市名映射（维护于仓库） |
| `troop_kinds_zh.json` | `desktop/tools/build_troop_kinds.py` + 游戏 pak/locres |

- 用户界面中文；Git 提交信息可用 Conventional Commits
