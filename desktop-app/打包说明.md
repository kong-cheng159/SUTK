# SUTK 修改器 · 桌面版打包说明

输出目录：`desktop-app\dist\SUTK修改器\`  
该文件夹即为 **绿色便携版**，可直接压缩分发。

---

## 1. 环境要求（仅打包机器）

| 工具 | 用途 |
|------|------|
| **Node.js 18+** | 构建 Vue 前端（`desktop/web`） |
| **Rust + Cargo** | 编译 Tauri 壳（`desktop-app/src-tauri`） |
| **Windows SDK / VS Build Tools** | Tauri 依赖 C 工具链 |
| **PowerShell** | 执行 `打包.ps1` |

游戏、Steam、Python 全局安装 **均不需要**（仓库自带 `python\`）。

---

## 2. 一键打包（推荐）

在 **PowerShell** 中：

```powershell
cd "E:\JZ-ROS\TEST\SUTK修改器_便携版\desktop-app"
.\打包.ps1
```

脚本会自动：

1. `desktop\web` 下 `npm install`（若无 `node_modules`）并 **`npm run build`** → 输出到 `desktop\static\`
2. 检查 **`src-tauri\target\release\sutk-mod.exe`** 是否存在（不存在则先编译，见下节）
3. 重建 **`dist\SUTK修改器\`**，复制 exe、Python、`SUTKMod.pyw`、`MemScan.py`、`desktop\` 等

成功时输出：`OK ...\dist\SUTK修改器`

---

## 3. 首次或升级 Tauri 壳

在 `desktop-app` 目录：

```powershell
cargo tauri build --release
```

或仅编译 release 二进制（与 `打包.ps1` 查找路径一致）：

```powershell
cd src-tauri
cargo build --release
```

产物：`src-tauri\target\release\sutk-mod.exe`  
打包脚本会将其复制为 **`dist\SUTK修改器\SUTK修改器.exe`**（中文产品名）。

> `tauri.conf.json` 中 `bundle.active` 为 `false`，当前 **不打 MSI/NSIS**，只产出文件夹便携版。

---

## 4. 打包脚本复制清单

| 来源 | 目标（dist 内） |
|------|-----------------|
| `target\release\sutk-mod.exe` | `SUTK修改器.exe` |
| 根目录 `SUTKMod.pyw`、`MemScan.py` | 同目录 |
| 根目录 `经验总结.md` | 同目录（说明页 API 也会读仓库根，dist 内保留一份便于用户看） |
| `desktop\server.py` | `desktop\` |
| `desktop\names_zh.json`、`cities_zh.json`、`troop_kinds_zh.json` | `desktop\`（存在则复制） |
| `desktop\static\` | `desktop\static\` |
| `python\` | `python\`（robocopy 整目录） |
| `desktop-app\*.txt`（如 `发给别人.txt`） | 根目录 |

**不会**自动复制：

- 根目录 **`config.json`**（用户首次运行后在 exe 旁生成；避免把开发者私人预设打进包）
- **`desktop\tools\`** 大文件（`repak.exe`、locres、`oo2core_*.dll`）——仅开发更新兵种表时需要

若发行版需要更新说明文档，可在 `打包.ps1` 中增加对 `桌面版使用说明.md` 等的 `Copy-Item`。

---

## 5. 增量更新 dist（exe 占用时）

若 **`SUTK修改器.exe` 正在运行**，无法删除整个 `dist` 文件夹。

做法：

1. 完全退出修改器（任务管理器确认无 `SUTK修改器.exe` / `python.exe` 占用该目录）。
2. 再跑 `打包.ps1`；或 **只覆盖**：
   - `desktop\static\`
   - `desktop\server.py`
   - `desktop\*.json`
   - `SUTKMod.pyw`

避免误删用户已在 dist 里生成的 `config.json`、`backup\`、`history\`。

---

## 6. 常见打包失败

| 现象 | 处理 |
|------|------|
| `missing exe: ...sutk-mod.exe` | 先 `cargo build --release` |
| `npm run build failed` | 在 `desktop/web` 手动 `npm install` / 查 Node 版本 |
| `robocopy failed` | 检查 `python\` 是否完整、路径权限 |
| `missing 经验总结.md` | 确保仓库根目录有该文件 |
| dist 里 `desktop` 变成 **单文件** | 目录损坏，删掉错误文件，重新 `打包.ps1` |

## 7. 兵种中文表更新（可选发行步骤）

游戏大版本更新后，兵种 ID 或文案可能变化：

```powershell
$env:OO2PATH = "...\desktop\tools"
# 需 repak.exe、oo2core_9_win64.dll，以及本机 Steam 游戏 pak 路径
python\python.exe desktop\tools\build_troop_kinds.py "D:\Steam\...\pakchunk0-Windows.pak"
```

生成 **`desktop\troop_kinds_zh.json`** 后重新 **`npm run build`**（若仅 JSON 则只需复制到 `dist\...\desktop\`）。

Oodle DLL 为 Epic 再分发组件，**请勿**在未确认许可的情况下随仓库公开传播；开发机本地放置即可。

## 8. 验证清单

打包完成后在 **`dist\SUTK修改器`** 中：

- [ ] 双击 exe，界面正常，顶部可选存档  
- [ ] `http://127.0.0.1:<port>/api/status` 返回 ok（port 见 `port.txt`）  
- [ ] `http://127.0.0.1:<port>/api/team-presets` → `presets.length >= 10`  
- [ ] `http://127.0.0.1:<port>/api/troop-kinds` → `kinds["49_2"]` 为中文  
- [ ] 编队预设页兵种列为中文  
- [ ] 应用修改后读档，游戏内数值变化  

---

## 9. 分发

将整个 **`SUTK修改器`** 文件夹打成 zip，附带：

- `发给别人.txt`
- 可选：`桌面版使用说明.md`

不要只发 exe。
